# Rolling-Window Exit Indexing: Synthetic Case Study

## Historical context

The private GELA project encountered an unresolved
time-based SELL intent generation problem.

A TSLA exit expected on November 3, 2026 was not
generated by the historical automated workflow.

Investigation identified a potential inconsistency
between a rolling 1200-bar window and a signal index
fixed at 1199.

## Demonstration

This repository contains a simplified, independently
written example of the general indexing failure mode.

If both the entry index and current signal index
are treated as fixed at 1199, a naive difference
does not advance with the passage of trading sessions.

The offline demonstration instead uses ordered session
identities and calculates their relative positions.

The example uses synthetic data and does not reproduce
the original production function line by line.

## Validation scope

Unit tests examine:
- Exit timing before and at T+6
- A shifting 1200-session window
- Missing entry identities
- Invalid session ordering
- Invalid holding periods

Passing these tests does not establish that the
historical defect was fixed or that a live trading
system is safe to operate.

The original automated trading system remains disabled.
